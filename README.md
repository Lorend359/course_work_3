# Course Work 3 — Vacancy Aggregator (HH.ru ⇄ PostgreSQL)

Скрипт собирает вакансии 10 крупнейших российских компаний через публичный API HH.ru, сохраняет их в PostgreSQL и предоставляет текстовый интерфейс для аналитических запросов.

---

## Возможности

* автоматическое создание БД `hh_vacancies` и необходимых таблиц;
* загрузка топ‑10 компаний в таблицу `employers`;
* сбор всех вакансий каждой компании и сохранение их в таблицу `vacancies`;
* 5 готовых SQL‑запросов (средняя зарплата, вакансии выше средней и т.д.);
* CLI‑меню для интерактивной работы.

---

## Требования

* **Python 3.12+**
* **PostgreSQL ≥ 13** (локально или в Docker)

Зависимости управляются **Poetry** (см. `pyproject.toml`).

---

## Установка

```bash
# клонируем репозиторий
git clone https://github.com/Lorend359/course_work_3.git
cd course_work_3

# устанавливаем зависимости в виртуальное окружение Poetry
poetry install --sync

# копируем пример переменных окружения и заполняем
cp .env.example .env        # впишите логин/пароль PostgreSQL
```

> **Важно:** пользователь из `.env` должен иметь право создавать новые базы данных.

### Содержимое `.env.example`

```dotenv
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=<ваш‑пароль>
DB_HOST=localhost
DB_PORT=5432
```

## Быстрый старт

```bash
# точка входа зарегистрирована как poetry‑script
poetry run cw3
# при необходимости можно запускать так
# poetry run python -m src.main
```

Меню программы

```
1 — Получить вакансии и загрузить в БД
2 — Компании и кол‑во вакансий
3 — Все вакансии
4 — Средняя зарплата
5 — Вакансии выше средней
6 — Поиск вакансий по ключу
0 — Выход
```

Пункт «1» выполняет полный ETL: создает БД → загружает 10 компаний → собирает вакансии → вставляет данные.
